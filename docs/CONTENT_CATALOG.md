# LIFE QUEST Future Content Catalog

この文書は、今後使う可能性がある要素を先に内部資産として保持するための索引。実装済み画面の仕様書ではない。

## 正本ファイル
- `src/content/fishMaster.ts` — 魚
- `src/content/worldMaster.ts` — 地域、建物、天候、季節イベント
- `src/content/economyMaster.ts` — 素材、農作物/畜産物、料理/加工レシピ、交易品
- `src/content/transportMaster.ts` — 機関車/貨車/客車、路線
- `src/content/societyMaster.ts` — NPC、クエスト雛形、実績/称号候補
- `src/content/progressionMaster.ts` — 装備、研究、博物館展示、宝物
- `src/content/contentManifest.ts` — 全カテゴリ件数と索引

## 運用
1. PREPAREDの追加は現在のゲームバランス、セーブ、図鑑母数を変更しない。
2. LIVEへ昇格する時に、入手先、用途、画像、価格/時間、既存セーブ移行、図鑑/Chapterへの影響を決める。
3. `assetKey` は画像差し替えとゲームIDを分離するための論理キー。実画像は後から追加できる。
4. 新しい地域やシステムを実装する時は、まずこのカタログから候補を選び、足りないものだけ追加する。
5. 数値バランスが未確定な項目は、将来設計を縛らないため用途タグやヒントに留める。

## 重要な考え方
世界に存在するデータ量と、スマホが同時に描画/計算する量は分離する。内部に大量の魚、NPC、地域、列車、装備が存在しても、その瞬間に必要な地域・画面の要素だけをロードする方向を維持する。
